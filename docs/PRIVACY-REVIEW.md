# Revisão de privacidade

O conteúdo público foi escrito como síntese técnica. Nenhum registro bruto foi copiado para esta árvore.

Foram excluídos da versão pública: caminhos absolutos de Windows, nomes de usuário e pastas pessoais, número de telefone presente no nome de um arquivo listado, transcrições brutas, logs de aplicativos, dados de dispositivo, código de terceiros e todos os binários. A cópia privada mantém os originais e um manifesto de integridade.

Não há diretório Git de origem importado: a árvore pública começa sem histórico de arquivos privados. A verificação local procurou padrões de credenciais, e-mails, telefone brasileiro e caminhos pessoais; não substitui auditoria de materiais que ainda não foram disponibilizados.
